## 1. 先加载本次更新

1. 保存鲸鱼与 DSH 中需要保留的修改。
2. 退出鲸鱼管理程序；从托盘完整退出 DSH，仅关窗口不够。
3. 打开 `D:\code\jingyu_wechat\WeChatAgent.exe`。DSH 必须启用 `D:\code\jingyu_wechat\packages\dsh-social-bridge-plugin`，停用其他旧目录的同名插件。
4. 重新打开 DSH，再启动鲸鱼服务。程序会检查插件版本与 DSH 进程启动时间，避免热加载表面成功、内部模块仍是旧代码。
5. 使用“打开微信”进入项目专用的 **4.1.10.27** 微信，登录小号；不要同时用其他版本占用发送端口。

本机准备时已给已绑定主人添加允许私聊和管理员权限，并启用小助手模式；之前的设置已留在本机备份，其他联系人没有增加。一般新用户仍需自己选择主人大号。

## 2. 会聊天的小助手

在“允许的聊天 → 设置此聊天 → 工作模式”选择“会聊天的小助手”，保留当前人设卡，保存设置。底层配置值仍为 `assistant`，已有配置可以继续使用。

- “你好呀”“我今天有点累”进入角色聊天。
- “帮我整理文件”“看看这个视频的评论”“任务：帮我选一份外卖”进入管理员任务。
- 管理员发送的文件进入任务通道，不会因文件没有文字说明而被当成闲聊。
- 显式说“聊天：……”可以切到日常聊天；多步任务续答不明确时，使用“继续任务：……”保留任务上下文。
- 只有指定管理员能执行任务。普通联系人也能聊天，但不会因此获得文件、电脑、外卖或通话控制权限。

角色卡只决定语气、称呼和性格。主人卡、朋友卡可以不同，允许读取的聊天事实按真实微信身份过滤；别人改昵称、换角色或自称主人都不能扩大权限。

## 3. B站与外卖

在“鲸鱼账户与记忆 → 外卖与 B站”打开相应平台窗口，登录、验证码和收货地址由你在窗口中完成，不需要复制 Cookie 或配置 Python。

可以在微信对小鲸鱼说：

```text
帮我找几个论文写作技巧的视频，看看评论区大家在争论什么。
读取这个 BV 号的字幕和热门评论，再展开其中一条楼中楼。
在美团帮我选一份 30 元以内的午饭，放入购物车后把费用和配送时间给我核对。
在淘宝闪购看看附近有什么合适的晚饭，先不要提交订单。
```

B站读取区分视频资料、字幕、评论与实际画面，没有拿到字幕时不会把标题简介说成看懂了视频。字幕只带入有限片段；评论属于第三方观点，不是工具指令。

外卖助手根据当前可见页面和本次快照里的控件操作，页面变化后先重新读取。加购请求有去重账本，结果未知时不盲目重复。提交订单、付款、验证码、登录以及发布/点赞/投币等按钮不会由该工具自动点击。商品规格、份数、配送费、地址与送达时间在购物车或结算页核对后，由你在平台窗口继续。

如果平台限制访问、页面没有暴露可识别控件或登录方式变化，程序会说明当前状态，需要你在窗口接手；不会编造订单号或宣称已经购买。

## 4. 安装双向音频通道

本机检测到 34 条音频设备记录，但没有虚拟音频通道。要让 AI 听见微信中的对方、再把 AI 声音送回微信，需要将这两个方向分开。

可使用 [Voicemeeter Banana 官方下载页](https://vb-audio.com/Voicemeeter/banana.htm)。它是独立的 VB-Audio 软件，采用 Donationware 许可；官方安装说明要求管理员安装并重启电脑。请先保存其他程序中的工作，再安装；本项目没有代你安装驱动或重启电脑。

安装并重启后打开 **Voicemeeter Banana**：

1. 右上角 **A1** 选择你的实体扬声器/耳机，建议先用 WDM 设备。
2. 在 **Voicemeeter VAIO** 虚拟输入条上开启 **B1**，关闭 **B2**。
3. 在 **Voicemeeter AUX** 虚拟输入条上开启 **B2**，关闭 **B1**。
4. 其他输入条先不要送到 B1/B2，避免混入本机麦克风或形成回声。需要自己听见对方时，可让 VAIO 条同时送到 A1。

按照下面表格选择设备，名称可能带括号或版本后缀：

| 软件位置 | 应选设备 |
| --- | --- |
| 微信的扬声器 | `Voicemeeter Input (VB-Audio Voicemeeter VAIO)` |
| 鲸鱼“微信声音传给 AI 的录音设备” | `Voicemeeter Output (VB-Audio Voicemeeter VAIO)`，即 B1 |
| 鲸鱼“AI 声音传回微信的播放设备” | `Voicemeeter Aux Input (VB-Audio Voicemeeter AUX VAIO)` |
| 微信的麦克风 | `Voicemeeter Aux Output (VB-Audio Voicemeeter AUX VAIO)`，即 B2 |

不要把两条虚拟输入同时送到同一个 B 总线。小鲸鱼采用轮流听说，合成回答期间暂停识别并清空积压；正确分离通道仍是避免回声的前提。

## 5. 开启来电接听

1. 在鲸鱼点击“一键准备语音环境”。解释器、依赖、中文识别模型均自动准备；本机已完成这一步，可直接检测设备。
2. 在“声音与本地语音测试”点击“试听小鲸鱼”。声音、音调和语速可调整；在线语音会把朗读文字发送到微软服务，不另需语音 API Key。DeepSeek 回答仍使用鲸鱼中绑定的 API Key。
3. 在“微信语音与视频 · 只接听”点击“准备通话控件”。操作仅限项目专用微信，用来激活辅助功能；当前 4.1.10.27 已验证可以从不可读状态激活。
4. 点击“检测音频设备”，按上一节选择输入/输出；人工检查微信设置，确认两条通道正确后勾选确认项并保存。声音设置和通话设备设置分开保存。
5. 选择主人大号，确保在允许私聊名单内、备注唯一，点击“开启来电接听”。界面应显示“等待所选联系人来电”。此时尚未采音、也不会主动拨号。
6. 用大号向小号发起语音通话。程序核对来电窗口的人物后点击接听；只有看到明确通话计时/连接证据才启动识别和 AI 回答。
7. 测试一句普通问候，再问“我最近在忙什么”，确认角色和允许的记忆正确。挂断后 AI 音频应停止，仍开启接听时继续等待下一次来电。
8. 再用大号发起视频通话，检查接听、通话声音与结束状态。小鲸鱼画面区暂时留空；若要传送立绘或虚拟形象，需以后接入虚拟摄像头并在微信选择。

通话默认最长五分钟，最多十五分钟；音频最多二十轮。账号或记忆权限变化、连接状态无法核对、识别/模型/发声异常时会停止 AI。异常状态不会直接重复接听或控制不明窗口；先在微信查看实际情况，再使用“清除已核对的异常状态”。

来电中的回答按该联系人的人设和记忆范围生成；不会把主人身份套给所有联系人。当前通话使用短期语音上下文，结束后清空，未自动把语音识别内容发布到跨聊天记忆。
