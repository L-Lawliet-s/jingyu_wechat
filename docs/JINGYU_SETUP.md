# 鲸鱼源码版配置与验收（功能参考）

首次安装请先阅读 [从零开始配置教程](GETTING_STARTED.md)。Python 已由软件自动管理，不再要求用户安装系统 Python、运行 pip 或填写解释器路径。

本版开发目录：`D:\code\jingyu_wechat`。现有运行版：`D:\code\jingyu_runtime`。两者独立；源码提交不包含你的账号、API Key、聊天或原运行版的配置。

## 一、启动开发版

本机已安装开发依赖并构建桌面程序，入口为：

```text
D:\code\jingyu_wechat\WeChatAgent.exe
```

打开管理界面不会等于完成微信连接。先只检查页面；准备真实收发测试时，再在旧版界面停止旧版聊天服务，避免两个项目同时处理同一个小号或占用同一组端口。

如果你在另一台电脑重新拉取代码，使用 PowerShell：

```powershell
Set-Location D:\code\jingyu_wechat
npm.cmd ci
npm.cmd run setup
npm.cmd run desktop:build
```

其余微信读取、Hook、DSH 和桥接依赖按首次配置页面及原版安装步骤准备；已有运行版的第三方组件并没有自动复制到新目录。完整安装步骤见 `docs/UPSTREAM_README.md` 和 `docs/WECHAT_HOOK.md`。

## 二、连接微信和模型

1. 使用当前匹配的微信 **4.1.10.27**。本版仍依赖上游对应版本的 Hook；不要按“最新微信”理解兼容范围。
2. 在开发版的首次配置/连接设置中选择小号，验证读取与发送账号一致。
3. 私聊白名单最初只添加你的大号；测试通过后逐个添加其他联系人。
4. 在 DSH 中加载新目录生成的桥接配置，完整退出并重开 DSH，再启动新目录的服务。不要同时加载两个不同工作区的同端口桥接。
5. 正常文本回复和表情包先通过，再验证本次新增功能。

**API 余额和 DSH 登录额度是两回事。** 这里保存的 Key 用于余额查询和新增语音测试；不会自动改写 DSH 的模型凭据。若原聊天使用 `deepseek-account`，它的消费不一定发生在这个 API Key 对应账户。若希望统一计费，请在 DSH 的官方 API 提供方中自行配置同一账户，并核对实际模型设置。

## 三、绑定主人与余额

1. 打开左侧“鲸鱼账户与记忆”。
2. 填入大号的真实微信 ID，与管理员设置使用的真实 ID 一致。昵称、备注和聊天中自称“主人”不产生权限。
3. 填入 DeepSeek API Key，点击“保存设置”。Key 以 Windows 当前用户加密方式保存在本机，不会回传给聊天模型，也不会出现在 Git 中。
4. 点击“刷新余额”。接口失败会显示查询失败或旧数据，不会把失败显示为 0 元。
5. 在大号私聊中问：“小鲸鱼，API 账户还剩多少钱？”其他联系人不能使用余额工具。

余额来自 [DeepSeek 官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)，不代表微信钱包、淘宝、美团钱包或 DSH 登录额度。默认缓存一分钟，连续询问不会反复查询。

## 四、共同记忆

| 当前对话 | 可读内容 |
| --- | --- |
| 主人大号 | 自己与各联系人的已收录私聊原话、笔记 |
| 联系人 A | 主人的可分享原话和已发布笔记、A 自己的原话与笔记 |
| 联系人 B | 主人的可分享原话和已发布笔记、B 自己的原话与笔记，读不到 A |
| 已允许群聊 | 默认不共享；桌面开启后只提供手动发布的主人笔记，不提供自动私聊资料 |

绑定主人后，普通私聊会自动形成可检索记忆，不需要先填写或说“记住”。主人说过“我在写论文”，其他私聊可以回忆；联系人说过“我吃了米饭”，主人可以问到，其他联系人读不到。只从本项目已有档案收录本人文字原话；AI 回复、引用、转发不作为新的本人原话向外共享。范围、首批导入数量和使用步骤见 [自动聊天记忆](CONVERSATION_MEMORY.md)。

主人消息可加“【私密】”；页面提供“设为私密”和“移出记忆”。重要约定仍可手动添加长期笔记，选择“只在与主人聊天时使用”或“共享给其他已允许聊天”。模型提交的共享笔记先进入“待确认”，点击“确认发布”才对其他聊天生效。

其他联系人只能建立自己的私有记忆，不能用“这是主人说的”改写主人记忆。检索在排序前就按权限过滤。每轮自动带入的记忆有限额，避免把全部记忆反复发送、增加费用。

删除或修改已发布共享项、关闭共享或更换主人时，会改变记忆版本并让旧模型会话失效。为防止从旧聊天档案重新带回被撤销的共享内容，该工作区之后会暂停自动向模型恢复旧历史档案；档案仍可在桌面查看，新聊天继续正常保存。已发送给别人的内容和截图不会被撤回。

这次没有自动导入旧版插件笔记。后续导入必须标明真实来源，无法确定归属的条目不能自动进入共享范围。

## 五、学习提醒

1. 先把接收人加入私聊白名单。
2. 在“工作日学习提醒”选择接收人，默认周一至周五、北京时间 09:00–18:00。
3. 间隔填 120 分钟，随机延迟上限填 15，效果为约 120–135 分钟一次。
4. 填提醒文字，确认对方愿意接收后添加。
5. 对方可在自己的私聊说“停止学习提醒”；桌面也可暂停或删除。

该提醒直接发送事先设置的文字，不为每次提醒调用模型。服务与微信需保持运行；错过超过 15 分钟的提醒不补发，下班、周末跳过。发送结果不明确时记录为“未确认”，不会盲目重发。

## 六、语音对话测试

当前实现只测试“听懂 → 回答 → 发声”，不会自行拨号，不会打开摄像头，也不会发送微信语音消息。当前仅使用主人身份的会话及允许给主人读取的记忆。通话期间对其他联系人匹配身份属于后续阶段。

先点击“一键准备语音环境”，软件自动检测并安装解释器与 Vosk、sounddevice 等依赖。无需手动配置 Python。准备完成后点击“检测设备”，查看输入设备、输出设备和 Windows 声音。

从 [Vosk 官方模型列表](https://alphacephei.com/vosk/models)下载中文模型，解压至方便的位置。在页面填写包含 `am`、`conf`、`graph` 等子目录的实际模型目录，不能填写 ZIP 路径。模型不随环境准备自动下载。

选择实际设备编号，填写模型目录，保存后点击“开始采集并对话”。建议先用耳机和普通麦克风测试，避免扬声器回授。默认五分钟、最多二十轮；随时可点“立即停止”。

音频识别与合成在本机进行；识别出的文字、当前人格和有限上下文发给 DeepSeek API。默认 `deepseek-flash`、关闭思考、输出上限 200 tokens；模型名仍需以账户实际可用为准，见 [官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/)。本版语音对话保留最近四组问答，停止后清空内存记录，不写长期聊天档案。

接入微信电话时，需要两条隔离通道：

```text
微信收到对方声音 → 通道 A → 本地识别
AI 合成声音      → 通道 B → 微信麦克风
```

本机已完成依赖和设备枚举，尚未完成虚拟音频路由、真实录音或接通电话验收。当前也不支持打断正在说话的 AI。拍一拍、原生语音气泡、自动拨号、自动接听和视频画面仍需下一阶段实现。
